# Contributing to Mocklet

Thanks for helping improve Mocklet.

## Pull requests

- Open a pull request for changes targeting `main`.
- Keep changes focused and include tests or verification evidence when behavior changes.
- Do not include credentials, private infrastructure details, captured request data, or other sensitive information.
- CI must pass before a change is merged.

The `main` branch is protected by repository rules. Pull requests require review, code-owner approval, passing CI, linear history, and resolved review conversations. Force-pushes and branch deletion are disabled. The repository owner account is the documented administrative bypass for maintenance and release operations.
