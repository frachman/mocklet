# Mocklet documentation

Mocklet is Mikrolyt M02: a disposable mock API for frontend, QA, and
integration work. The public journey is:

1. Create a mock.
2. Define routes and responses.
3. Use the runtime URL.
4. Iterate against the contract.

Resources expire automatically. Use test data and keep management credentials
private.
