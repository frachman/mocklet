# Mocklet agent guidance

Read `docs/product/PRD.md`, `docs/memory/current-state.md`, `docs/memory/decisions.md`, and `docs/memory/next-actions.md` before continuing work.

Mocklet is a public repository. Never commit secrets, real infrastructure details, user payloads, or credentials. Keep anonymous usage first-class and disposable. Do not add shared identity, arbitrary code execution, billing, AI, or speculative infrastructure without a separately documented decision.

Use small milestone commits. Update docs and memory with material behavior changes. Verify the actual Git state before assuming repository facts.
